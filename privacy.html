CLIPFORGE

Política de Privacidade

Última atualização: 16 de setembro de 2026

Este texto descreve o protótipo local atual. Atualize a política caso você passe a operar servidores, analytics, cadastro de usuários ou outros tratamentos de dados.

1. Visão geral

O ClipForge foi projetado como uma ferramenta de processamento de vídeo executada no computador do usuário. Arquivos gerados e credenciais configuradas pelo usuário permanecem localmente, salvo quando o próprio usuário autoriza o envio a uma plataforma conectada.

2. Dados processados

O aplicativo pode processar links de vídeos fornecidos pelo usuário, arquivos de vídeo e áudio, transcrições, legendas, títulos e configurações de publicação. Para integrações autorizadas, pode processar tokens de acesso e informações necessárias da conta retornadas pela API da plataforma.

3. Finalidades

Esses dados são usados para gerar cortes, transcrever áudio, criar legendas, permitir a revisão de publicações e executar ações expressamente solicitadas pelo usuário.

4. TikTok e outros serviços

Quando o usuário conecta uma plataforma externa, os dados necessários são enviados à API dessa plataforma somente para executar a ação autorizada. O tratamento realizado pela plataforma externa é regido pelas políticas dela.

5. Armazenamento

No protótipo desktop, tokens e arquivos de configuração ficam na pasta local credentials. O usuário não deve compartilhar essa pasta. Se uma versão futura armazenar dados em servidores, esta política deverá ser atualizada antes dessa funcionalidade ser oferecida.

6. Compartilhamento

O ClipForge não vende dados pessoais. Dados são compartilhados com serviços conectados apenas quando necessário para a funcionalidade escolhida e autorizada pelo usuário.

7. Segurança

O usuário deve proteger o computador e as credenciais de acesso. Segredos de cliente e tokens não devem ser publicados ou enviados a terceiros.

8. Exclusão e revogação

Como os dados do protótipo são locais, o usuário pode excluir os arquivos gerados e credenciais armazenadas no computador. Autorizações concedidas a plataformas externas também podem ser revogadas nos controles oferecidos por essas plataformas.

9. Alterações

Esta política poderá ser atualizada quando as funcionalidades ou práticas de tratamento de dados mudarem.
